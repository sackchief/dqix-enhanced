# Functions recompiled as <name>_orig, with the runtime's wrap_<name> around them
# (the game's own code still does all the work; the runtime only watches).
# <module> <address> <name>   (named, so the runtime's hook doesn't depend on
# the address: tools/region.py moves the addresses for the European ROM)

# Draws one glyph of a font into a tiled text canvas (4 bits per pixel):
# func_0205b36c(canvas, glyph, x, y, [sp] colour, [sp+4] font). Watched by
# text_hd.c, which notes where each letter went so the GPU renderer can draw
# it again in high resolution (Graphics > HD text).
main 0205b36c glyph_tiled

# Draws one glyph into a plain (not tiled) 4-bit buffer: func_02045864(x, y,
# glyph, buffer, [sp] width, [sp+4] height, [sp+8] colour, [sp+12] font). The
# battle messages over the field: each letter (with its shadow or outline) in
# a 16x16 texture, drawn by the 3D engine. Watched by text_hd.c, like above.
main 02045864 glyph_plain

# memcpy: the tags of letters follow them when the game copies them itself
# (the textures above go through a staging buffer).
main 02001a40 memcpy

# The 11 items a character's 3D model is built from (torso, legs, face,
# hairstyle twice, arms, feet, head, weapon, shield, accessory):
# func_02072afc(object index, out part ids[11], out item ids[11]). Every place
# that builds a character's model asks this first. Watched by transmog.c
# (Mods > Transmog), which notes what each character wears.
main 02072afc look_items
# Fills a party member's item cache (11 entries, +0x194 in its data) from the
# list above; the game's numbers are added up from this cache, so transmog.c
# leaves it as the game fills it (it only learns the chosen looks here).
main 020deef4 fill_items
# Makes the file name of one part of a character's model from a cache entry:
# func_02072e94(out name, object, list index, entry, [sp] cache). transmog.c
# shows the chosen look in the cache for the time of this call only.
main 02072e94 part_name
# The overlays are the same in both ROMs (only the main code moves).
# func_ov017_0218f5a4(field, object, 0, 0, [sp] force): makes a party member's
# model again if its items changed (or forced); transmog.c notes the field.
ov017 0218f5a4 model_check
# The party on the field, once a frame: after Reload transmog.ini or
# Mods > Transmog, transmog.c makes the party's models again at its end
# (the check above, forced), so a new look shows at once.
ov017 0218e8c8 party_frame

# Places a camera around the point it looks at: func_0202e5d8(camera, yaw,
# height, distance) stores them at +0x70/+0x74/+0x78 and puts the camera
# (+0x04) at the point looked at (+0x10) plus (0, height, the rest of the
# distance) turned by the yaw. The field camera goes through it every frame.
# Watched by free_camera.c (zoom, with Modern > Free camera): for the field
# camera, the offset from the point looked at is scaled afterwards; the
# stored height and distance stay the game's own.
main 0202e5d8 camera_orbit
# The field camera, once a frame: func_020a212c(camera, input on). free_camera.c
# notes which camera object it is (only that one is zoomed) and that it ran
# with L/R taken (the right stick turns it only then). On land it is called
# through func_020a20d8; on the boat by other code; func_020a2b38 calls it with
# input off to work out the default view (not counted).
main 020a212c field_camera
