**The newest work, less tested.** Use the stable release for your main
adventure; try this one in its own folder with a copy of your save.

**New in v34-nightly2**

- **Fewer messages through the relay** ("Join a friend" with a code): the
  host sends one message for all its friends instead of one each, about a
  sixth fewer with three players and a third fewer with four, so the
  relay's daily allowance lasts longer. Older versions still work with it.
- **When the relay is full for the day**, joining with a code now says so
  and what to do meanwhile (the host's address, or a free virtual LAN:
  Tailscale, ZeroTier or Radmin VPN), instead of a vague error.

**New in v34-nightly1** (since stable v33)

- **An in-game menu** (first version): **Esc**, or the controller's
  **Home / Guide** button, or **Select + Start** together. Every option of
  the menu bar, in a list over the game, for a controller, keyboard or
  mouse: up / down to choose, A or Enter to pick, B or Esc to go back. The
  game waits while it is open. Exit and Fullscreen are in it (Game, View),
  so Esc no longer quits or leaves fullscreen by itself. The menu bar is
  still there on Windows; both are made from one list of options, so they
  always match. Its button can be changed in Game > Controls.
- **Messages and questions show inside the game** instead of in windows
  of their own: About, the help texts, "Reset?", "Quit?", the update
  offer, the bug report's questions. Left / right choose a button.
- **The volume is changed right in the menu** (Game > Volume: left /
  right).
- **Nothing opens a window of its own any more**:
  - **Controls**: every action with its keys and controller button in a
    list; pick one, then press the new key or button.
  - **Save file**: export and import choose a folder or a save in a list
    inside the game (starting in Downloads, with Documents, Desktop and
    the game's folder one step away).
  - **Typing** (your name, a friend's code, a bug report's description):
    type on the keyboard, or with a controller or the mouse use the
    keyboard drawn on the screen (A a letter, B delete, X space,
    Y capitals, Start done).
  - **Playing with friends**: the code to give out, who has joined, and
    Start / Copy the code / Cancel, inside the game.
