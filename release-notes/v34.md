DQIX Enhanced v34: an in-game menu, Linux and Mac, and RecompLauncher.

**What's new since v33**

The in-game menu
- **Every option inside the game**: press **`** (the key under Esc), the
  controller's **Home / Guide** button, or **Select + Start** together. A
  list over the game for a controller, keyboard or mouse: up / down to
  choose, A or Enter to pick, B or Esc to go back. The game waits while it
  is open. On Windows the menu bar is still there too, and both always
  match.
- **Nothing opens a window of its own any more**: Controls, exporting and
  importing your save, typing names and codes (with a keyboard drawn on
  the screen for controllers), hosting and joining friends, sending a bug
  report, the volume, and every message and question all happen inside
  the game.
- **Esc** leaves fullscreen, as before. In a window it opens the menu too.
  (Mods: holding the game's own textures to compare moves from ` to \.)

Play on more systems
- **Linux (beta)**: the in-game menu makes everything work without
  Windows' menu bar. Install with the AppImage or `./BUILD.sh <your ROM>`.
  Now also on ARM64 Linux, and joining friends with a code works over
  https. Updating from inside the game still needs Windows for now.
- **macOS (experimental)**: a native Mac build, with the menus in the
  Mac's own bar. It builds and starts, but nobody has played it on a real
  Mac yet: Mac players, please try it and send reports.
- **Steam Deck (experimental)**: should work through the Linux AppImage
  (it brings its own build tools). Deck owners, please tell us how it goes:
  a proper Steam Deck version is the plan for v35.
- **RecompLauncher**: the game can be installed and updated from
  RecompLauncher (coming soon to its list): it asks for your own ROM and
  builds the game, on Windows and Linux.

Mods
- **Transmog** (Mods menu): your characters can look as if they wore other
  equipment, while what they really wear, and every number in the game,
  stays the same. The item names come from your own ROM. Off while playing
  with friends.

Playing with friends
- **Fewer messages through the relay**: the host sends one message for
  all its friends instead of one each. The relay now has room for
  everyone, all day.

Thanks to Jack Gallagher (Linux ARM64 and the Mac build), Xemor (https on
Linux), the transmog's author, and everyone who sent bug reports, here and
on GitHub.

**How to install**: download *Source code (zip)* below, unzip it and
double-click `Install Dragon Quest IX.bat` (Linux: `./BUILD.sh` with your
ROM). **Already on v33?** The game offers the update when it starts (or
Help > Check for updates): your saves and settings are kept.

**Playing with friends**: everyone needs the same version, so all of you
update to v34.

The plans for what comes next (the Steam Deck, direct connections between
friends, and more fixes for Dynamic Widescreen) are in ROADMAP.md.
