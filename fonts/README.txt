HD text (F1): the game's letters drawn again at full
resolution with these TrueType fonts. The game folder gets a copy (game/fonts);
any font can be put there instead.

  main.ttf    the game's main (serif) font    Merriweather Medium (SIL Open Font Licence)
  small.ttf   the game's small font           Nunito SemiBold (SIL Open Font Licence)
  labels.bin  the labels the game has as pictures ("Back", "HP", "Lv."...):
              made by tools/hd_labels.py (see there). It holds hashes of the
              labels' tiles, nothing of the game's graphics.

Missing fonts: those letters are made from the game's own pixels, smoothed.
